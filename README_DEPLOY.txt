- app.js

GitHub Pages Deployment:
1. Neues GitHub-Repository anlegen, zum Beispiel: zeitrechner
2. Diese drei Dateien in das Hauptverzeichnis hochladen
3. Repository auf Public stellen
4. In GitHub auf Settings gehen
5. Links Pages öffnen
6. Bei Source: Deploy from a branch wählen
7. Branch main und Ordner / (root) auswählen
8. Speichern
9. Kurz warten
10. GitHub zeigt dann die Live-URL an

Hinweis:
- Es werden keine Build-Tools benötigt
- Alles läuft direkt als statische Webseite
- Eingaben werden im Browser per localStorage gespeichert
