# Arbeitszeitrechner für GitHub Pages

## Datei
- `index.html`

## So online stellen
1. Bei GitHub einloggen
2. Neues Repository erstellen, z. B. `arbeitszeitrechner`
3. Repository auf **Public** stellen
4. Datei `index.html` hochladen
5. Committen
6. In das Repository gehen
7. `Settings` öffnen
8. Links `Pages` öffnen
9. Bei `Build and deployment`:
   - `Source` = `Deploy from a branch`
   - `Branch` = `main`
   - Ordner = `/ (root)`
10. `Save`
11. Kurz warten
12. Die angezeigte URL öffnen

Typische URL:
`https://DEIN-GITHUB-NAME.github.io/arbeitszeitrechner/`
